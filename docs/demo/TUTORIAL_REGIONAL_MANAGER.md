## 📋 Overview

As a **Regional Manager**, you have access to:
- View all outlets in your region (Singapore)
- Monitor regional performance and trends
- Manage cases and escalations for your region
- View staff and workforce data
- Chat with Athena AI

**Note:** You CANNOT see other regions' data or access HQ admin features.

## 🚨 Step 3: Regional Alerts & Cases

### Accessing Alerts:
1. Click **Active Escalations** in sidebar
2. See alerts for ALL Singapore outlets
3. Each alert shows: Outlet, Type, Severity, Status

### Regional Alert Management:
| Action | How To |
|--------|--------|
| **View All Alerts** | Default view shows all SG alerts |
| **Filter by Severity** | Use severity dropdown |
| **Filter by Outlet** | Select specific outlet |
| **Create Case** | Click alert → Create Case |

### Case Management:
1. Click **Case Management** in sidebar
2. See cases for your region
3. Assign staff to cases
4. Track SLA compliance

### Case Workflow:
```
NEW → ACKNOWLEDGED → IN_PROGRESS → RESOLVED
```
