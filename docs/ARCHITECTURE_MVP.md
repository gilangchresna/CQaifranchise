## MVP Data Flow

```
1. POS transaction occurs (simulator or real)
       │
2. POST /functions/v1/pos-webhook
       │  (HMAC validated, outlet mapped, currency normalized)
       ▼
3. INSERT sales_transactions
       │
4. system_status.last_txn_at updated
       │  (Dashboard "Live" indicator fires)
       ▼
5. coordinator-pipeline cron (every 1 min)
       │  - Z-score: compare today vs 30-day baseline
       │  - Stockout: predict 7-day risk
       │  - If anomaly → INSERT alerts
       ▼
6. Dashboard polls: dashboard-full
       │  - Aggregated revenue, count, currency
       │  - daily_breakdown for chart
       │  - active_alerts count
       ▼
7. User sees:
       │  - "Live" indicator
       │  - Updated revenue chart
       │  - Alert in queue
       ▼
8. User clicks alert → Case created
       │  - case-create edge fn
       │  - Assigned to outlet owner
       ▼
9. User asks Athena Chat:
       │  "Why did outlet X drop today?"
       │  - athena-chat fetches real data
       │  - Claude generates NL explanation
       ▼
10. Case resolved in workflow
```
